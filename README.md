# Memory Triggered Emotion Classifier

This repository contains the **Memory Triggered Emotion Classifier**, a machine learning model built using Hugging Face Transformers. The model is designed to classify a user's emotional state based on text input, with future applications in recalling relevant past memories or logs when specific emotional states are detected.

## Model Objective

The goal of this project is to help users reflect on their emotions by identifying them from textual input. This model can serve as the core of a therapeutic chatbot that recalls emotionally tagged memories.

## Features

- Emotion classification from text
- Built using Hugging Face Transformers
- Ready for integration with memory-recalling applications or chatbots
